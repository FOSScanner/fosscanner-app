## Draft user-facing release notes

### Easier document review

- Edit a saved page's appearance directly, with crop changes still available.
- Restore the original review crop, select the full image, or reset brightness
  and contrast without changing the crop, filter, or rotation.
- Read adjustment values and clearer Preview page / Add page / Save changes
  actions, with improved accessible slider announcements.
- See explicit full-image fallback guidance when page edges are not detected.
- Distinguish cancellation from skipping an image in a gallery batch.

### More reliable feedback

- Save only after the latest adjustment preview is ready; retry failed previews.
- Keep drafts after sharing without a repetitive cleanup question.
- Retry draft-save failures from a persistent warning.
- Use deletion Undo without unrelated notifications replacing it. Undo expires
  after four seconds; a new deletion replaces the previous Undo, and export or
  confirmed clearing deliberately discards it.

### Clearer export and code inspection

- Use compact PDF export controls with optional on-device searchable text on
  Android, distinct progress/sharing feedback, and responsive home layouts.
- Inspect and copy complete barcode results and review link hostnames before
  opening HTTP/HTTPS destinations.

Scans and OCR remain on-device. Drafts remain temporary OS-managed cache data,
not durable saved PDFs. No new accounts, telemetry, or scan network processing.

## Device acceptance checklist

Use synthetic/non-sensitive documents. Record failures rather than assuming
that widget tests establish native camera or accessibility compliance.

- [ ] Camera capture: accept and cancel; verify gallery import remains usable.
- [ ] Gallery: one image and several images; skip an image, finish the batch,
      cancel/back, and confirm already accepted pages remain intact.
- [ ] Crop: detection success/fallback, drag corners, Reset crop, Use full image;
      confirm no page edges disappear in fallback or after reset.
- [ ] Appearance: all filters, brightness/contrast bounds, reset, rotate;
      ensure saved output matches the latest preview and stale callbacks cannot
      save pending/failed settings. Exercise Retry preview if failure can be
      reproduced safely; otherwise mark that scenario untested.
- [ ] Existing page: zoom preview, direct appearance edit, Adjust crop,
      system back/cancel without changes, and Save changes.
- [ ] Delete: Undo within four seconds and automatic disappearance afterward,
      including the final page; rapid deletions restore only the newest page.
- [ ] Drafts: restart and restore an unfinished document; clear only through
      confirmed Clear all. Check persistent retry feedback with controlled
      fault injection if available, not by exhausting real device storage.
- [ ] Reorder pages and restart; confirm persisted order and page numbering.
- [ ] Export/share: image-only and Android searchable PDF, export cancellation,
      share success/dismissal, retained pages, selectable OCR text where expected,
      and explicit clearing. Do not equate share-sheet completion with delivery.
- [ ] Barcode: long/multiline result, copy, HTTP/HTTPS hostname review, dismiss,
      and short-landscape layout without obstructing camera controls.
- [ ] Portrait/landscape, light/dark, 200% text, safe-area insets, final grid row,
      and TalkBack focus/labels/reading order. Test touch-target usability.

Record results:
